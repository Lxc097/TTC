# 接入测试指南 · 三个外部 API

> **不要把真实 key 写进任何被 git 跟踪的文件。** 仓库是公开的。
> key 通过私聊/群公告/密码管理器传递，落地只写进 `.env`（已被 `.gitignore` 排除）。

---

## 0. 一句话

三个能力都是**可插拔、可单独关闭**的。没配 key 就跑 mock，界面和流程完全一样，只是数字/文案/转写换成假的和模板。

```
FacePhys  → 测量：心率、信号质量、呼吸率、活体
DeepSeek  → 分析：读转写判断有没有绕开关键信息、写追问、写报告摘要
百炼 ASR  → 听写：语音转文字（会议纪要）
```

---

## 1. 配好 .env（唯一的落地位置）

```bash
cd backend
cp .env.example .env        # Windows: copy .env.example .env
```

然后按需打开：

```ini
# —— FacePhys：真实心率（一次约 17 万 token，很贵，默认关）——
VISION_PROVIDER=facephys
TTC_API_KEY_ID=<Key ID>
TTC_API_SECRET=<Secret>

# —— DeepSeek：语义分析 + 写追问（很便宜）——
LLM_ENABLED=1
LLM_API_KEY=<sk-...>

# —— 百炼：语音转写（很便宜）——
STT_ENABLED=1
STT_API_KEY=<sk-ws-...>
```

**省钱建议**：联调阶段只开 LLM + ASR，`VISION_PROVIDER` 保持 `mock`。
这样整套流程（纪要、语义触发、追问、报告）都能测，且几乎不花钱；
FacePhys 只在最终验证真心率时开一次。

## 2. 申请入口

| 能力 | 平台 | 说明 |
|---|---|---|
| FacePhys | <https://www.facephys.com/console/skills> | 一对 `Key ID` + `Secret`。鉴权是 HMAC-SHA256 签名，不是 Bearer |
| DeepSeek | <https://platform.deepseek.com> | 单个 `sk-` 开头的 key |
| 百炼 ASR | <https://bailian.console.aliyun.com> | `sk-ws-` 开头。模型用 `qwen3-asr-flash` |

> FacePhys 的 Key ID / Secret 容易抄错（`0` 和 `O`、`l` 和 `I`）。
> 别从截图抄，**从控制台复制文本**。

## 3. 验证（一条命令）

配好 `.env` 后：

```bash
cd qiyueduan/backend
pip install -r requirements.txt
python tools/verify_keys.py
```

它会依次检查：

| 检查项 | 花不花钱 | 说明 |
|---|---|---|
| FacePhys 健康检查 | 免费 | `GET /api/video/health`，不需要鉴权 |
| FacePhys 签名 | 免费 | 请求一次上传签名（不真正检测，不扣 token） |
| DeepSeek | 免费 | `GET /models` |
| 百炼 ASR | 免费 | `GET /models` |
| 百炼真实转写（`--asr`） | 极少量 | 用内置示例音频跑一次完整转写 |

只验证签名和连通性跑：`python tools/verify_keys.py`
连转写一起验：`python tools/verify_keys.py --asr`

## 4. 每个能力的降级行为（配错了不会崩）

| 关掉/配错 | 表现 | 你能测到什么 |
|---|---|---|
| FacePhys | `signal` 来自 mock，心率是假的曲线 | 信号带、触发、取证、报告全流程 |
| DeepSeek | 追问退回 8 条模板，语义通道置 0 | 模板提示、采纳率、报告 |
| 百炼 ASR | 前端推一条 `status{degraded}`，手打输入可用 | 纪要存储、广播、重连恢复、报告 |

**所以联调时不要等三个 key 齐了才开始。** 缺哪个就少测哪块，其余照常。

## 5. 常见报错对照

| 现象 | 原因 |
|---|---|
| FacePhys `401 invalid API key` | Key ID 抄错（最常见）；或签名算法不对（应为 `Base64(HMAC-SHA256(secret, timestamp))`） |
| FacePhys `403 error code: 1010` | User-Agent 被 Cloudflare 拦了。代码里已固定成浏览器 UA，不要改 |
| FacePhys `VIDEO_UPLOAD_INCOMPLETE` | 上传的视频小于 10240 字节 |
| FacePhys `VIDEO_PROCESSING_UNPROCESSABLE` | 不是合法视频，或编码服务端解不了 |
| DeepSeek `401` | key 失效或复制残缺 |
| 百炼 `InvalidParameter` | 音频格式/长度不对；`qwen3-asr-flash` 只吃带格式头的音频 |
| 转写一直没结果 | 先看后端日志有没有 `[stt] ...`，没有就是浏览器根本没发上来 |

## 6. 安全约定

1. **不提交**：key 只写 `.env`（gitignore 已覆盖）。
2. **不截图**：发群里的截图会被转发，也容易被 OCR。
3. **不进前端**：所有 key 只在后端使用，浏览器永远不碰。
4. **赛后轮换**：开发期传过、贴过、截图过的 key，比赛结束统一换掉。
5. 交付队友用「私聊发一段文本」或「一次性密码管理器链接」，不要用仓库。
